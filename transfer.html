How to get your code

From Transfer Code (dashboard Export button):

Open dashboard with your data
2

3
Copy code -> paste above -> select "Transfer Code"
From Browser Console (Safari/Chrome):
1
Open dashboard with your data in Safari
2
Safari -> Develop -> Show JavaScript Console
3
Paste the console command -> press Enter
4
Cmd+V here -> select "Raw JSON"
